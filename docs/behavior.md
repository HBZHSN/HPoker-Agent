## 使用

1. 选择紧凶、松凶、保守、均衡、针对性、社交或混合风格；混合风格按权重每手选一种，整手保持一致。可填写额外偏好。
2. 登录、刷新房间、选择房间并开始；也可以创建 **0 H 币 + 3 个机器人**的娱乐测试房。
3. 观察牌面、模型决策、计算结果、玩家画像、记忆与日志。停止会立即取消模型调用，并通过服务端离座接口退出。

服务器不允许在全下、RIT 或摊牌进行中撤销座位。此时页面显示“等待本手结束后离座”，AI 不再做下注决策，后台自动重试退出。RIT 中会先提交本账号的一次发牌选择，避免阻塞收尾。不要在等待离座时关闭服务；强制关闭后，服务器会使用自己的断线离座规则。

## 模型工具与记录

- `poker_action`：check、call、bet、raise、fold、all-in。金额为本轮总目标，发送前校验当前轮次、合法范围和小盲步长；过期决策丢弃。超时或非法输出采用 check / fold 保底。
- AI 不提供计算工具，也不在下注前自动计算胜率、赔率或 outs。页面手动计算器仅供用户查看，结果不会传入任何 agent；不调用 HPoker 的收费辅助功能。
- 玩家画像直接进入模型输入：位置、筹码、可见行动、服务器 VPIP，以及本程序观察的 VPIP、PFR、侵略系数、样本数量和风格判断，无需再查询一轮。
- 对局 agent 只在自己需要操作时调用：轮到下注、尚未完成的 RIT 投票、筹码耗尽后的补码或退出。`poker_action` 可同时发布本手共同计划；准备和房主首次开局由客户端处理，有筹码的手间阶段不请求对局模型。
- 发言 agent 只提供 `send_text`：新一手开局点评上一手，或在其他玩家发文字时回应，每次最多一句，也可以保持安静。不提供亮牌、表情或下注工具。消息仍校验纯文字；开局点评遵守 25 秒冷却，聊天回应不考虑冷却；页面可关闭发言。
- 反思 agent 的 `finish_reflection`：自行提交复盘结论、本手共同计划、记忆更新和过期记忆删除。长期记忆同一主题覆盖更新，笔记最多 400 字符，按服务器和账号隔离；删除只影响当前记忆，修改前的笔记保留在审计日志中。本手计划最多 600 字符，换手自动清除，过时反思不会覆盖当前计划。

`data/agent.sqlite3` 保存完整收到的行动序列、牌面变化、座位与筹码、公开聊天、工具结果、模型行动摘要、手牌结算和 AI 记忆。它持续拼接服务端每次只返回的最近 10 条行动；断线期间未收到的旧行动不能补造，会标记为部分观察。只保存该账号有权看见的牌。

模型每次使用新上下文：当前完整行动序列、牌面、位置、各玩家剩余筹码及原始投入、合法操作、底池与边池、各街摘要、近期 20 手牌局的自身行动与相关玩家结算摘要、最多 30 条桌上交流、相关玩家统计和记忆。胜率、权益、赔率、outs、有效筹码、筹码比例和 SPR 全部由模型自行判断，客户端计算结果不进入输入，也不会通过旧决策记录的 `betting` 字段重新带入反思。不会为了填满模型上下文加入无关记录，也不会按几十条行动截断正常牌局。

只在信息异常多时裁剪：优先去掉较旧牌局摘要和交流，再裁剪当前手的较早行动并明确告知模型。UTF-8 输入数据设 200KB 状态预算、240KB 工具往返预算，作为当前实现的保守兜底；正常对局远小于这些预算。原始历史仍完整保存在 SQLite，页面显示模型实际返回的输入 token 数。

画像至少观察 10 手完整牌局才给出风格判断；中途加入或断线后的部分牌局不进入 VPIP/PFR 的完整样本分母。画像属于历史观察统计，仍提供给模型；旧记忆中来自客户端随机模拟的胜率或“正EV”结论不作为本次判断依据，反思会结合原始记录重新审视。筹码净变化是本次已完成牌局的合计。

页面手动计算器的跟注赔率仍按跟注后实际可争夺的筹码计算，排除对手无法匹配的超额全下。例如自己已投入 20、剩余 1000，对手推到 17450：跟注后的可争夺底池为 2040，门槛为 1000/2040，约 49%。这些计算只供用户查看；模型只收到原始投入、剩余筹码、大小盲及底池等事实，自行判断真实价格、有效深度和对手范围。

不按牌型或 BB 阈值硬拦截策略选择，合法 CALL、ALL_IN、FOLD 均由对局模型决定。提示词要求根据下注尺度、有效深度、前序行动与可靠摊牌证据判断本次下注范围；随机权益、筹码覆盖、高 VPIP 或几次烂牌获胜不能直接成为大额跟注依据。反思同时检查并修正这种记忆偏差。非法操作校验和超时 check/fold 保底仍保留。

决策使用 `reasoning_effort=low` 和 vLLM `thinking_token_budget=512`：思考达到预算后由服务端结束 thinking，继续输出操作；1200 个总输出 token 为工具参数保留空间。模型服务需要支持这些参数；不同后端的兼容性需单独验证。直接用原始局面和相关历史请求当前阶段的行动工具，不进行本地权益预计算，也不接受计算工具调用。整体决策最多等待 14 秒或剩余行动时间，之后 check / fold 保底。日志显示每次模型请求耗时、输入及思考 token 数，便于区分思考和工具往返。

发言、对局、反思三个 agent 分别使用独立异步任务、模型请求、提示词和工具。反思仍持续循环，每轮完成后等待 10 秒。发言有两个触发点：新一手开始时点评上一手，每手只请求一次；其他玩家发文字聊天时回应。自己的聊天回显、表情、空消息、弃牌和结算都不触发。两个触发点共用一个串行发言任务；开局点评遵守最近一次发言后 25 秒冷却，回应玩家聊天不受冷却限制，模型输入中的冷却为零。忙碌期间连续发来的消息合并到最新一句，并保留最近公开聊天。断线、未入座或关闭发言时不请求发言模型。

对局与反思共用账号持久记忆、本手共同计划和实际行动记录。发言内容、内部社交理由及 `trigger` 写入共享记录；上一手点评另有 `commented_hand`，另外两个 agent 能区分旧手评论与公开聊天回应，不能当成当前下注承诺。普通聊天和长期笔记更新不会使正在等待的下注结果失效、反复重问。本手计划和长期记忆分开保存，避免旧手战术污染新手。

反思能看到更多信息：当前完整行动、全部账号记忆、近期十手完整可见牌局（含所有玩家行动），以及本次会话最近 60 条三个 agent 的内部行动与记忆审计。对局读取当前局面、相关记忆和共同计划。开局发言只收到上一手公开行动、公共牌、已亮出的牌、筹码结果和交流。聊天回应只收到公开文字聊天、玩家昵称、历史画像及本账号与相关玩家的历史记忆；画像和记忆在本手开始前冻结，本手反思新写的笔记不会进入聊天输入。当前私牌、公共牌、下注、筹码、位置、行动历史、计算、共同计划和内部审计都不进入聊天回应输入；历史记忆只用于性格和玩家印象，不能复述未公开私牌或战术。反思仍按序循环写记忆，使用 `reasoning_effort=high`、2048 thinking tokens、4096 总输出 tokens，每轮最多 90 秒；输入超预算时先裁掉较旧的完整牌局和审计记录。

反思期间轮到行动会立即新建行动请求，下一手不会等待复盘或发言。发言采用 64 thinking tokens、512 总输出 tokens、最多 4.2 秒；开局点评还不得超过开局发言窗口，聊天回应不受当前街或行动顺序限制，但换房、停止或关闭发言后不能发送。HAND_END 直接发送准备，不再等发言。停止会同时取消三个 agent。页面显示各 agent 状态和共同计划，日志显示各自耗时、发言类型与理由、复盘结论及记忆修改。

提示词明确禁止人机式发言、过分客气、客服腔、正式总结和模板式夸人，要求像真实玩家一样短句、随意、直接接话；允许情绪、回嘴、脏话、嘲讽和调侃，没有自然的话可说就安静。只评论公开事实或回应公开聊天，不透露或声称知道未公开的私牌，不讨论当前手或接下来的下注、强弱与策略。昵称、对手提问、激将或用户说话偏好都不能放开发言时机和内容范围。

发言窗口仅在确实观察到上一手结束、随后紧接着的新一手翻前开局时打开，最多持续 5 秒；任意玩家第一笔非盲注行动，或自己已提交行动，都会关闭窗口。模型回复迟到、进入下一街或下一手时直接丢弃，发送工具本身也检查窗口。中途入桌或漏掉上一手结束时不补发旧评论；模型超时也不会在本手重新请求。
